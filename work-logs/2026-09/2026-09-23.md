## Timecard

**IISS-824 — RPA LLM Agent (Ask Citco RPA): Bedrock Agent Configuration**

- AgentId SSM Storage — Decoupling Agent Identity from Buildspec
The `buildspec.yml` was hardcoding the Bedrock AgentId for the `update-agent` instruction apply step. This made the buildspec brittle: any agent recreation would require a manual buildspec edit. The AgentId is now stored in SSM Parameter Store during initial stack deployment, and the buildspec reads from SSM at build time. This decouples the agent identity from the CI/CD configuration and supports automated agent recreation workflows.

**IISS-1050 — SMB Retry Decorator: TRANSFER_FAILED Prevention (SD #15645338)**

- IISS-1050 PR #13 Merge — Observability and Email Module Integration
Pull request #13 was merged, bringing in the Sep 18 observability improvements: the unified `scheduled_report_email.py` notification module with Pydantic request/response models, end-to-end trace ID wiring from SQS message through to the dispatcher, `report_date` derivation logging, tenacity retry logs in `get_report_status.py`, and the corresponding unit test updates.

**IISS-971 — MESO Scheduled Reports Infrastructure**

- EventBridge to Scheduler Migration Attempt — DST-Aware Scheduling Investigation
An attempt was made to migrate the MESO scheduled report EventBridge Rules to EventBridge Scheduler to enable timezone-aware cron expressions (required for correct DST handling across Australian and North American time zones). The migration was reverted after discovering that the Scheduler target configuration required additional KMS `GenerateDataKey` and IAM role permissions not present in the existing stack. The investigation documented the exact permission gaps for the Sep 24 clean re-implementation.

- Pipeline Rollback Verification — EventBridge Rules Confirmed Restored
Following the Scheduler revert, the Bitbucket pipeline was triggered to confirm the rollback deployed cleanly and the original EventBridge Rules were restored to the correct state in the DEV environment.
