## Timecard

**IISS-971 — Migrate Scheduled Reports: APScheduler → EventBridge Scheduler → SQS**

- SQS_SR_* Constants and Import Path Correction — Configuration Completeness
The application code was missing the `SQS_SR_QUEUE_URL`, `SQS_SR_DLQ_URL`, and `SQS_SR_VISIBILITY_TIMEOUT` constants required by the dedicated SQS poll loop. These were added to the configuration module alongside a default value for `SD_PASSWORD` to prevent `KeyError` crashes on local development runs. The `process_scheduled_report` module import path was also corrected following the module restructure.

- Local Development Profile — DLQ URL Addition
The `dlq_url` field was missing from the local development profile for `scheduled_report_sqs`, causing the DLQ client to fail on instantiation during local testing. The field was added to align the local profile with the DEV and PROD configuration schemas.

- IISS-971 PRs #10 and #11 Merge — Configuration Fixes Integrated
Pull requests #10 and #11 were merged to bring the configuration fixes into the main branch. Two DEV pipeline deployments were triggered to verify the complete IISS-971 integration (SQS poll loop + EventBridge rules + application config) in the live DEV environment.

**IISS-971 — MESO Scheduled Reports Infrastructure**

- Scheduled Reports Dead Letter Queue — Failure Capture and Retention
A Dead Letter Queue (`MesoSRDLQ`) was added for the scheduled reports SQS queue. The `RedrivePolicy` was configured with a maximum receive count of 3, ensuring messages that fail processing are captured after the retry threshold rather than being discarded. `DeletionPolicy: Retain` was set to preserve the DLQ across stack deletions for post-incident analysis. The DLQ ARN was exposed as a CloudFormation output for downstream IAM grant references.

**IISS-507 — Infrastructure Inventory API**

- Fan-Out Branch Merge — Upstream Fixes Incorporated
The `release/IISS-507` branch was merged into the fan-out feature branch to incorporate the URL-encoding fix and PLATFORM_REGIONS update from the previous day, keeping the fan-out implementation current with upstream corrections.

**IISS-824 — RPA LLM Agent (Ask Citco RPA)**

- Structlog Dependency — Lambda Runtime Import Error Resolution
The `structlog` package was missing from the `requirements.txt` of several Lambda functions that imported `log_config.py`. This caused `ModuleNotFoundError` at Lambda cold start. The dependency was added to all affected Lambda package requirements files.
