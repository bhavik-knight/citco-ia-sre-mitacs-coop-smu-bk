## Timecard

**IISS-507 — Infrastructure Inventory API: SQS Enrichment and Regions Endpoint**

- SQS Queue Type Field — Authoritative AWS Attribute Detection
A `queue_type` field was added to all SQS queue entries in the inventory API. The type is determined by querying AWS with `QueueAttributeName: All` and inspecting the returned attributes: `FifoQueue=true` yields `fifo`, the presence of `RedriveAllowPolicy` yields `dlq`, the combination yields `fifo-dlq`, and the absence of both yields `standard`. This classification enables the Grafana dashboard to filter and display queues by operational role without requiring manual tagging.

- GET /regions Endpoint — Per-Platform Region Configuration
A new `GET /regions` endpoint was added to the inventory API, returning the complete `PLATFORM_REGIONS` configuration as a structured JSON response. This endpoint enables the Grafana dashboard provisioner to dynamically discover which AWS regions each platform operates in, replacing the previously hardcoded region list in the dashboard template.

- IISS-507 PR #1923 Merge — Queue Type Feature Integrated
Pull request #1923, implementing the `queue_type` detection feature, was merged into `release/IISS-507` following successful CI validation. The merge incorporated the queue type field, the gitignore update for `pr-*.md` files, and the PLATFORM_REGIONS documentation update.

**IISS-824 — RPA LLM Agent (Ask Citco RPA): Bedrock Agent Buildspec Hardening**

- Thinking Configuration Removal — Claude Sonnet 5 Compatibility
The Bedrock agent CFN template contained a `thinking` configuration block carried over from an earlier Claude model version. Claude Sonnet 5 does not support the `thinking` parameter, and its presence was causing agent deployment failures with a parameter validation error. The configuration block was removed, restoring successful agent deployments.

- Buildspec DRAFT Clean Step — Stale Agent State Prevention
CloudFormation deployments were leaving the Bedrock agent in a stale `DRAFT` state between deployments. A `delete-agent-version` clean step was added to `buildspec.yml` before the CFN deploy, ensuring the agent DRAFT is cleared and the new version is applied cleanly on each deployment.

**IISS-971 — MESO Scheduled Reports Application**

- Dedicated SQS Poll Loop PR #7 — First IISS-971 Feature Merged
Pull request #7, implementing the dedicated SQS poll loop for EventBridge scheduled reports, was merged to the application main branch. The PR included the `poll_scheduled_report_sqs.py` daemon thread, the `ScheduledReportMessage` Pydantic model, and the idempotency service with `SELECT FOR UPDATE` locking.
