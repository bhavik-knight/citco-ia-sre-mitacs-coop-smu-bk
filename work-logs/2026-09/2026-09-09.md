## Timecard

**IISS-507 — Infrastructure Inventory API: Region and IAM Fixes**

1. CitcoWorks Region Discovery — Comprehensive Service Scan Finding
A comprehensive scan of deployed AWS services across all IA platforms was conducted to validate the `PLATFORM_REGIONS` configuration. The scan identified that the `citcoworks` platform has active resources in `us-east-1` that were not reflected in the existing configuration. The region was added, ensuring the inventory API returns complete results for CitcoWorks resources across all active regions.

2. S3 Cache IAM Policy — Cross-Region Write Access
The IAM policy governing cache writes to S3 was granting `PutObject` only on specific bucket prefixes derived from a subset of known regions. As new regions were added to `PLATFORM_REGIONS`, the cache writer function was failing with access denied errors when attempting to write to prefixes for the new regions. The policy was updated to allow `PutObject` on all prefixes within the inventory cache bucket.

**IISS-824 — RPA LLM Agent (Ask Citco RPA): PROD Upgrade and Agent Fixes**

3. PROD Bedrock Agent Upgrade — Claude Sonnet 5 Deployment
The PROD Bedrock agent was upgraded to Claude Sonnet 5 (`zm2k2apek28k`), reflecting the quality and formatting improvements validated in DEV. The model alias was updated in the agent configuration, and the deployment was monitored through the first PROD query cycle to confirm response quality.

4. Event Service NA Count Fix — Null-Safe In-Progress Handling
The `get_events_count` function was crashing with an unhandled exception when the Event Store returned `NA` as the count value for in-progress processes. The `NA` value occurs when a process has been initiated but no events have been recorded yet. A null-safe check was added to handle this case gracefully, returning zero rather than raising an exception.

5. Process Status Table Format — Agent Response Consistency Restoration
A previous instruction update had inadvertently changed the agent's default format for process status responses from a structured table to a bullet list. The explicit table format instruction was restored to the instruction set, returning consistent tabular output for all process status queries.

**IISS-971 — MESO Scheduled Reports Infrastructure**

6. Scheduled Reports Infrastructure Revert — Clean Slate for Re-Implementation
The Sep 4 SQS queue and EventBridge rules CloudFormation resources were reverted after deployment revealed missing KMS `GenerateDataKey` permissions required for EventBridge to publish encrypted messages to the queue, and incorrect IAM role assignments on the ECS TaskRole. Rather than patching the deployed stack, a full revert was chosen to enable a clean re-implementation with correct permissions from the start on Sep 11.
