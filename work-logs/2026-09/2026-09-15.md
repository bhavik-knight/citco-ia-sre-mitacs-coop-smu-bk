## Timecard

**IISS-507 — Infrastructure Inventory API: Fan-Out Scheduler and URL Fixes**

1. AWS Console Deep-Link URL Encoding — Operator Click-Through Fix
The console deep-link URL generated for each SQS queue contained un-encoded characters (`?`, `=`, `&`) that caused the URL fragment to break when pasted into browsers or embedded in dashboards. Full percent-encoding was applied to all URL components in the fragment, restoring correct click-through navigation to the AWS SQS console for each queue entry.

2. Fan-Out Multi-Region Refresh Pattern — Parallel Cross-Region Inventory
The inventory refresh scheduler was restructured to implement a fan-out pattern: both the manual API trigger and the bi-weekly cron now distribute refresh requests across all entries in `PLATFORM_REGIONS` in parallel, rather than sequentially. This reduces the total refresh latency from the sum of all per-region latencies to the latency of the single slowest region, which is significant for platforms spanning multiple AWS regions.

**IISS-971 — Migrate Scheduled Reports: APScheduler → EventBridge Scheduler → SQS**

3. is_primary() and Heartbeat Mechanism Removal — Architecture Simplification
The `is_primary()` function and its associated heartbeat polling mechanism were designed for a multi-instance ECS deployment where only one instance should process scheduled reports at a time. The migration to a dedicated SQS-based dispatch model eliminates the need for primary election, as SQS visibility timeouts provide natural mutual exclusion. Removing this mechanism reduces startup overhead and eliminates a class of timing-related bugs.

4. SIGMATWO Fund Transfer Fix — date_columns Parameter
The `transfer_to_share_drive()` call for the SIGMATWO fund was missing the `date_columns` parameter, causing a `TypeError` when the function attempted to format date-typed DataFrame columns for the share drive file. The parameter was added, aligning SIGMATWO's invocation with the other fund handlers.

5. IISS-971 PR #9 Merge — Clean Implementation Integrated
Pull request #9 was merged, integrating the clean IISS-971 implementation (dedicated SQS poll loop, `is_primary` removal, `sigmatwo` date fix) into the main branch following review.

**IISS-971 — MESO Scheduled Reports Infrastructure**

6. SQS_SR_URL ECS Task Definition Wiring — Environment Variable for Poll Loop
The ECS task definition was missing the `SQS_SR_URL` environment variable required by the newly added SQS poll loop in the application code. The variable was added, pointing to the `MesoSRQueueURL` CloudFormation output of the infrastructure stack. Without this variable, the poll loop would fail to connect to the queue on ECS task startup.
