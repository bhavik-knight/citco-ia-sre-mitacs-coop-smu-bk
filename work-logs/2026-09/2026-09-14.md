## Timecard

**IISS-507 — Infrastructure Inventory API: SQS Console Deep-Link**

- SQS Console URL Generation — Raw Endpoint Replaced with Deep-Link
The SQS queue entries in the inventory API response were returning the raw queue API endpoint URL, which is not a human-navigable address. The URL was replaced with a properly formatted AWS Console deep-link that opens the queue directly in the SQS console. The URL is generated dynamically from the queue ARN components (region, account ID, queue name) and URL-encoded to handle special characters in queue names.

**IISS-824 — RPA LLM Agent (Ask Citco RPA): Agent Reliability and Test Quality**

- SharePoint Source URL Guard — Conditional Citation Display
The Bedrock agent was including a `source_url` field in every response, even when the Knowledge Base metadata did not contain a SharePoint URL. This produced empty or malformed citation links in responses for documents that were not sourced from SharePoint. A guard condition was added so that the `source_url` field is only populated and displayed when the Knowledge Base metadata record contains a non-empty SharePoint URL.

- log_config.py Buildspec Copy — Lambda Package Completeness
The structured logging configuration module (`log_config.py`) was not being copied into individual Lambda function packages during the CodeBuild deployment step. Lambda functions importing `log_config` would encounter `ModuleNotFoundError` at cold start. An explicit copy step was added to `buildspec.yml` for each Lambda package directory, ensuring the module is present in every deployed function.

- Unit Test Failures — 8 Pre-Existing Test Failures Resolved
Eight unit tests had been failing since before the current development cycle due to outdated mock configurations, incorrect import paths following module reorganisations, and assertions against changed response formats. All eight failures were diagnosed and resolved, restoring a passing test suite and enabling reliable CI validation for subsequent changes.
