- `template-api.yaml` — `MetricsFunction` + Integration/Route/Permission
- `tests/unit/lambda_api/test_handlers.py` — `TestHandlerMetrics` (16 tests, all passing)

**Key design decisions:**
- Batched `GetMetricData` (<=500 queries/call) — avoids 10 TPS CloudWatch throttle
- Cache-first: reads resource list from S3 cache, returns 400 if cache empty
- Stat routing: `p50`/`p90`/`p95`/`p99` -> `ExtendedStatistic`; others -> `Stat`
- Resources with no CW data included with `datapoints: []` (no silent omissions)
