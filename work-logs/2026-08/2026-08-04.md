**Architecture Discussion with Horace — EventBridge vs APScheduler for AExeo Report UI (59 min call)**

Horace is implementing a scheduler for the AExeo Report UI and consulted on the architecture choice between APScheduler and AWS EventBridge, as Kishor had recommended EventBridge. Discussed pros and cons:

- **APScheduler**: No AWS cost, runs in-process — but requires manual process lifecycle management, does not survive container restarts, and Kishor had previously encountered memory issues running it alongside the main application process.
- **AWS EventBridge Scheduler**: Fully managed by AWS, no manual lifecycle management required, minimal cost (~$1/month for typical usage), reliable at scale — the same pattern I used for the 5-minute interval ongoing alarm re-notifications in IISS-487.

Agreed that EventBridge Scheduler is the better fit for a production AExeo Report UI. The managed reliability and elimination of memory contention outweigh the marginal cost. Horace confirmed he would proceed with EventBridge.
