%% ── AWS SERVICES ──────────────────────────────────────────
\multicolumn{2}{l}{\textit{\textbf{AWS Services}}} \\
\hline
AMG & Amazon Managed Grafana — a fully managed Grafana service for building observability dashboards backed by AWS data sources. \\
CloudFormation & AWS Infrastructure-as-Code service for provisioning and managing AWS resources via declarative YAML/JSON templates. \\
CloudWatch & AWS native observability service providing metrics collection, log storage, alarms, and dashboards for all AWS services. \\
ECS & Amazon Elastic Container Service — a managed container orchestration service for running Docker containers on AWS. \\
ECR & Amazon Elastic Container Registry — a managed Docker image registry for storing and versioning container images. \\
EKS & Amazon Elastic Kubernetes Service — a managed Kubernetes service for running containerized workloads. \\
IAM & AWS Identity and Access Management — service for managing user, role, and policy-based access to AWS resources. \\
MSK & Amazon Managed Streaming for Apache Kafka — a fully managed Apache Kafka service for real-time data streaming. \\
RDS & Amazon Relational Database Service — managed relational database service supporting MySQL, PostgreSQL, and Aurora. \\
S3 & Amazon Simple Storage Service — scalable object storage used for data lakes, backups, and Lambda deployment packages. \\
SAM & AWS Serverless Application Model — an extension of CloudFormation that simplifies packaging and deploying Lambda-based applications. \\
SNS & Amazon Simple Notification Service — pub/sub messaging service that fans out alarm notifications to email and Lambda subscribers. \\
SQS & Amazon Simple Queue Service — managed message queue service used as a trigger mechanism between Lambda functions. \\
SSM & AWS Systems Manager Parameter Store — service for storing configuration values and non-sensitive secrets as named parameters. \\
X-Ray & AWS distributed tracing service that generates service maps and trace waterfalls for Lambda, ECS, and API Gateway requests. \\

%% ── SRE / OBSERVABILITY ───────────────────────────────────
\multicolumn{2}{l}{\textit{\textbf{SRE and Observability}}} \\
\hline
ADOT & AWS Distro for OpenTelemetry — AWS-maintained distribution of the OpenTelemetry collector for ECS/EKS distributed tracing. \\
APM & Application Performance Monitoring — software category providing end-to-end visibility into application health and performance. \\
Error Budget & The permitted amount of unreliability before an SLO is breached; calculated as \(1 - \text{SLO target}\). \\
Four Golden Signals & The SRE framework's minimum instrumentation set: Latency, Traffic, Errors, and Saturation. \\
IaC & Infrastructure-as-Code — the practice of managing cloud resources through version-controlled declarative configuration files. \\
SLI & Service Level Indicator — a specific metric that measures one of the four golden signals for a service (e.g., Lambda error rate). \\
SLO & Service Level Objective — the target threshold set on an SLI that defines acceptable system performance (e.g., error rate $<$1\%). \\
SRE & Site Reliability Engineering — a software engineering approach to operations focused on reliability, scalability, and automation. \\

RPA & Robotic Process Automation — software automation of repetitive, rule-based tasks using Blue Prism or UiPath platforms. \\
SMU & Saint Mary's University — the academic institution in Halifax, Nova Scotia, where this MCDA program is based. \\
TDD & Test-Driven Development — a software practice where tests are written before the code they verify. \\
