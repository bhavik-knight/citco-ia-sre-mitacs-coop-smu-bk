\chapter{Achievements \& Business Value}
\label{chap:achievements}

Working on the IA-IT-SRE Infrastructure at Citco Technology Management,
I achieved several significant milestones across observability platform
development, API engineering, and production support operations. These
accomplishments highlight my technical growth and the business value
delivered during the co-op placement.

    \item \textbf{CloudWatch Monitoring Platform:} Inventoried the complete AWS

\section{Business Value}
\label{sec:business_value}
% ────────────────────────────────────────────────────────────

The shift from a purely reactive to a proactively monitored infrastructure
is the central business value proposition of this co-op placement's work.

\subsection{Incident Detection: From Hours to Seconds}

The Apr~17, 2026 Meridian incident---in which approximately 9 million Kafka
messages queued, producing a 7.5-hour processing delay affecting multiple
client funds---was detected only because a fund administrator noticed missing
outputs. No automated alarm existed.

The \texttt{EstimatedMaxTimeLag} alarm deployed as part of IISS-487 directly
addresses this gap:

\begin{itemize}
    \item \textbf{Before:} Detection required human observation of missing
          downstream outputs, with latency of 2--3 hours when incidents began
          outside working hours.
    \item \textbf{After:} CloudWatch alarm fires within \textbf{30 seconds} of
          threshold breach, routing notification directly to the SRE team.
\end{itemize}

This improvement from multi-hour manual detection to sub-30-second automated
alerting represents a qualitative step change in the team's ability to contain
fund-impacting incidents before they reach business-level severity.

\subsection{Operational Efficiency: Unified Fleet Visibility}

Prior to this work, the IA-SRE team had no single view of all Lambda functions,
ECS clusters, and EC2 instances under their operational mandate. Resource
discovery was ad hoc and frequently lagged deployments by days or weeks.

The Grafana dashboard and inventory API together deliver:

\begin{itemize}
    \item \textbf{Continuous visibility:} A single workspace replaces navigation
          across six separate AWS console tabs to assess platform health.
    \item \textbf{Machine-readable inventory:} The REST API enables downstream
          automation including tag compliance checks and dynamic alarm
          threshold recalibration.
    \item \textbf{Hidden issue discovery:} Container Insights immediately
          surfaced a previously invisible CPU saturation pattern on one of the
          Meridian Action Processor services.
\end{itemize}

\subsection{Knowledge Transfer and Platform Resilience}

Each support rotation produced documented incident summaries in the team's
Confluence knowledge base. The CAIS hotfix analysis elevated a credential
caching vulnerability to a platform-wide architectural concern, informing
future RPA credential-handling guidelines and improving overall system
resilience.

These achievements reflect my ability to deliver production-grade engineering
solutions while contributing directly to the operational reliability of
Citco's Intelligent Automation platform.
