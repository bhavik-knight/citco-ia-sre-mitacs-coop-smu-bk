# 🧾 Observability Platform Design (AWS + Grafana + Pyroscope)
---

## 1. Overview
### 1.1 ObjectiveDesign and deploy a centralized observability platform on AWS using CloudFormation to provide:
- Metrics monitoring
- Distributed tracing
- Continuous profiling
- Centralized dashboards
- Alerting

The system must support **4 Golden Signals**:
- Latency
- Traffic
- Errors
- Saturation

## 4. CloudFormation Stack Design

---

### 4.1 Stack Structure


root-stack.yaml
├── network.yaml
├── compute.yaml
├── observability.yaml
└── grafana.yaml

---

### 4.2 Network Stack (network.yaml)

#### Resources:
- VPC
- Public/Private Subnets
- Internet Gateway
- Security Groups

#### Requirements:
- Allow inbound:
  - Grafana (3000)
  - Pyroscope (4040)
- Allow internal service communication

---

### 4.3 Compute Stack (compute.yaml)

#### Resources:
- EC2 / ECS Services
- Auto Scaling Group

#### Configuration:
- Application deployment
- Attach IAM roles
- Enable CloudWatch agent

---

### 4.4 Observability Stack (observability.yaml)

---

#### ✅ CloudWatch

**Resources:**
- Log Groups
- Metric Filters
- Alarms

**Metrics to enable:**
- CPUUtilization
- Memory usage
- RequestCount
- Error count

---

#### ✅ X-Ray

**Resources:**
- X-Ray Daemon (if EC2/ECS)
- IAM Role:
  - `AWSXrayWriteOnlyAccess`

**Configuration:**
- Enable tracing for:
  - Lambda
  - API Gateway
  - Services

---

#### ✅ Pyroscope

**Deployment:**
- EC2 or container service

**Ports:**
- 4040 (UI/API)

**Configuration:**
- Enable CPU & memory profiling
- Attach persistent storage (optional)

---

#### ✅ Logging

**Resources:**
- CloudWatch Log Groups

**Requirements:**
- Structured logs (JSON)
- Retention policy (e.g., 30 days)

---

### 4.5 Grafana Stack (grafana.yaml)

---

#### Deployment Options:
- EC2 instance OR
- Managed Grafana (AWS Managed Grafana)

---

#### Resources:
- Grafana Server
- Security Group

---

#### Data Source Configuration:

| Data Source | Config |
|------------|--------|
| CloudWatch | IAM role |
| X-Ray | Enabled tracing |
| Pyroscope | HTTP endpoint |

Example:

Pyroscope URL: http://pyroscope:4040

## 8. Security Design

---

### IAM Roles:
- EC2 role for:
  - CloudWatch
  - X-Ray
- Grafana role for:
  - CloudWatch read
  - X-Ray read

---

### Network Security:
- Restrict ports:
  - Grafana (3000)
  - Pyroscope (4040)
- Use private subnets where possible
