# Knowledge Base

Consolidated internship knowledge base for the IA-SRE team work at Citco Technology Management.
Source: `smu/` folder documents, work-logs, and KnowledgeBase notes.

## Structure

Files are organized in a flat structure with date-prefixed names for chronological context.
Binary files (.one, .onetoc2, .docx, .pdf) from the original `smu/` folder are referenced
but not duplicated here — see `smu/KnowledgeBase/` for those originals.

## Categories

- `onboarding_*` — Day 1 setup, access requests, tooling
- `dashboard_*` — Grafana/CloudWatch SRE dashboard work (IISS-487)
- `rpa_support_*` — RPA support shift documentation and ticket resolutions
- `hotfix_*` — Production hotfixes and RCAs
- `xray_*` — AWS X-Ray tracing investigation and configuration
- `container_insights_*` — ECS Container Insights audit and reversion
- `infra_*` — AWS infrastructure resources, Lambda, ECS, EC2 inventories
- `workshop_*` — Training week and KT session notes
- `todos_*` — Weekly task lists and priorities
